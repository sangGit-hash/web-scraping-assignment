# Multi-Source Web Scraping & Data Consolidation Pipeline

## Overview
An end-to-end Python pipeline designed to scrape, clean, validate, deduplicate, and consolidate semi-structured data from two distinct public web sources:
1. **Books to Scrape** (`https://books.toscrape.com/`)
2. **Quotes to Scrape** (`https://quotes.toscrape.com/`)
